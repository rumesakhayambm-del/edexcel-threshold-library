How to add your data

  1. Tap Download CSV template.
  2. Open the CSV in Google Sheets or Excel and replace the example rows with your verified thresholds.
  3. Keep the column headings unchanged. Add one row for each grade threshold and component/session combination.
  4. Save or download as CSV, then tap Import your CSV data.
  5. Check the results, then publish the website using a website builder or hosting service.

Recommended CSV columns: qualification, subject, specification, component, year, session, grade, threshold, max_mark, source. Use one row per grade per component. For a modular qualification, record unit/component boundaries according to that qualification's official rules.
